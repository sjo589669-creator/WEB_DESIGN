WHAT IS A PLUG-IN?

플러그인이란

THE BASICS01 · DEFINITION

기본 의상과 액세서리

크롬, 엣지, 파이어폭스 같은 브라우저는 그 자체로 완성된 옷이다. 여기에 기능 하나를 덧붙이는 작은 프로그램, 그것이 우리가 흔히 '플러그인'이라 부르는 확장 프로그램이다.

브라우저는 웹 페이지를 열고, 읽고, 보여 주는 일을 한다. 하지만 사람마다 필요한 기능은 다르다. 광고 없는 화면을 원하는 사람, 밤에도 눈이 편한 어두운 화면을 원하는 사람, 웹 페이지에 쓰인 글꼴과 색상을 바로 알고 싶은 디자인 전공생까지. 브라우저 회사가 이 모든 기능을 기본으로 넣을 수는 없다. 그래서 브라우저는 '덧붙일 수 있는 구멍'을 열어 두었다. 그 자리에 끼우는 부품이 확장 프로그램이다.

일상에서는 '플러그인'과 '확장 프로그램'을 같은 뜻으로 쓰는 경우가 많다. 그러나 엄밀히는 다르다. 예전의 플러그인은 플래시(Flash) 플레이어처럼 브라우저 바깥에서 만든 별도 프로그램을 브라우저 안에 끼워 넣는 방식이었다.

컴퓨터 깊숙한 곳까지 접근할 수 있어 강력했지만, 그만큼 보안 사고의 통로가 되기 쉬웠다. 결국 주요 브라우저는 이런 방식의 플러그인 지원을 거둬들였고, 플래시도 2020년 말 공식 지원이 끝났다.

지금 우리가 설치하는 것은 대부분 확장 프로그램(Extension)이다. 흥미로운 점은 확장 프로그램이 우리가 수업에서 배운 HTML, CSS, 자바스크립트로 만들어진다는 것이다. 툴바에서 아이콘을 눌렀을 때 뜨는 작은 창도 하나의 HTML 페이지이고, 다크 모드처럼 화면 색을 바꾸는 기능은 결국 웹 페이지에 CSS를 한 겹 덧입히는 일이다.

즉, 확장 프로그램은 낯선 기술이 아니다. 웹 페이지를 만드는 재료로 브라우저 자체를 꾸미는 일. 이 책이 확장 프로그램을 '코디'라는 말로 설명하는 이유다.

“플러그인은 옷 속에 꿰매 넣은 부품,
확장 프로그램은 언제든 뗄 수 있는 브로치에 가깝다.”

THEN · 과거

플러그인 (Plug-in)

  • 브라우저 밖에서 만든 별도 프로그램
  • 예: 플래시 플레이어, 자바 애플릿
  • 컴퓨터 깊은 곳까지 접근 → 보안 위험 큼
  • 현재 주요 브라우저에서 지원 종료

NOW · 현재

확장 프로그램 (Extension)

  • HTML · CSS · 자바스크립트로 제작
  • 예: 광고 차단, 다크 모드, 번역
  • 브라우저가 정한 권한 안에서만 동작
  • 공식 스토어에서 설치·삭제가 간편

같은 페이지, 다른 착장

확장 프로그램은 웹 페이지의 원본을 바꾸지 않는다. 내 브라우저에서 보일 때만 그 위에 한 겹을 덧입힌다. 광고 차단과 다크 모드를 함께 착용한 전후를 비교해 보자.

다크 모드의 원리 — CSS 덧입히기

/* 태그 선택자로 색을 뒤집는다 */
body { background-color: #121212;
       color: #E8E2D8; }
a { color: #E3A79F; text-decoration: none; }
a:hover { color: #ffffff; }

광고 차단의 원리 — 숨기기

/* 속성 선택자로 광고 영역을 골라 */
div[class="ad-banner"],
img[src="ads.png"] {
  display: none;  /* 가시 속성 */
}

i.

덧입히기

콘텐츠 스크립트가 페이지에 CSS를 추가한다. 선택자로 대상을 고르고 속성으로 모양을 바꾸는, 수업 시간의 바로 그 방식이다.

ii.

덜어내기

필요 없는 요소는 display: none으로 감춘다. 광고 차단은 '빼는 코디'의 대표 주자.

iii.

되돌리기

확장 프로그램을 끄면 원래 모습으로 돌아온다. 원본 사이트는 그대로이고, 내 화면만 달라진다.

uBlock Origin Lite

“모든 코디의 기본, 깨끗한 흰 셔츠”

화면을 어지럽히는 광고와 추적 스크립트를 걷어낸다. 페이지가 가벼워져 로딩도 빨라진다. 크롬은 새 확장 규격(Manifest V3)으로 바뀌면서 기존 uBlock Origin 대신 Lite 버전을 제공하며, 파이어폭스에서는 기존 버전을 그대로 쓸 수 있다.

무료 · 오픈소스Chrome · Edge · Firefox

코디 팁: 학교 포털처럼 광고 차단 때문에 기능이 깨지는 사이트는 '이 사이트에서 끄기'로 예외 처리.

Bitwarden

“어디에나 어울리는 트렌치코트”

사이트마다 다른, 길고 복잡한 비밀번호를 대신 만들고 기억해 준다. 하나의 마스터 비밀번호만 기억하면 된다. 코드가 공개된 오픈소스라 많은 사람의 검증을 거쳤고, 개인 사용자는 무료로 쓸 수 있다.

기능에 비해 과한 권한

신호: “모든 웹사이트의 데이터 읽기 및 변경”

설치 버튼을 누르면 브라우저가 이 확장 프로그램이 요구하는 권한을 보여 준다. 다크 모드처럼 모든 페이지에 스타일을 입혀야 하는 도구라면 넓은 권한이 이해된다. 하지만 계산기, 시계, 배경화면 같은 단순한 도구가 모든 사이트의 데이터와 방문 기록까지 요구한다면 그건 옷 사이즈가 맞지 않는 것이다.

“예쁜 시계 위젯”을 추가하시겠습니까?

  • 모든 웹사이트에 있는 사용자의 데이터 읽기 및 변경
  • 방문 기록 읽기
  • 알림 표시

취소확장 프로그램 추가

02

얼굴 없는 디자이너

신호: 개발자 웹사이트·연락처·개인정보처리방침이 없음

믿을 만한 브랜드는 라벨에 이름과 주소를 남긴다. 스토어 상세 페이지에서 개발자 이름을 누르고, 공식 웹사이트와 개인정보처리방침이 있는지 확인하자. 수집하는 데이터를 밝히지 않는 확장 프로그램은 입지 않는 편이 낫다.

03

유명 브랜드를 닮은 짝퉁

신호: 인기 앱 이름 + “Pro”, “Plus”, “2026” 같은 꼬리표

인기 있는 확장 프로그램의 이름과 아이콘을 살짝 바꿔 올린 복제품이 있다. 이름만 보고 고르지 말고, 사용자 수와 개발자 이름이 공식 웹사이트에서 안내하는 것과 같은지 대조한다. 가장 안전한 방법은 공식 홈페이지에 걸린 스토어 링크로 들어가 설치하는 것.

04

어색한 평판

신호: 사용자는 적은데 별 다섯 개 리뷰만 잔뜩

한두 줄짜리 비슷한 칭찬 리뷰가 같은 시기에 몰려 있다면 의심하자. 별점이 낮은 리뷰부터 읽어 보는 습관이 도움이 된다. “설치 후 광고가 늘었다”, “검색 엔진이 바뀌었다” 같은 후기는 그 자체로 경고다.

05

정식 매장 밖에서 파는 옷

신호: “파일(.crx)을 받아 직접 설치하세요”, “개발자 모드를 켜세요”

공식 스토어는 등록 전에 검토를 거친다. 블로그나 메신저로 받은 설치 파일, 개발자 모드를 켜라는 안내는 그 검토를 건너뛰는 길이다. 수업 실습으로 내가 직접 만든 확장 프로그램을 시험할 때가 아니라면 따르지 않는다.

06

멈춘 시계, 바뀐 주인

신호: 몇 년째 업데이트 없음 · 갑자기 개발자 이름이 바뀜

오래 방치된 확장 프로그램은 보안 구멍이 막히지 않은 채로 남는다. 반대로 인기 확장 프로그램이 다른 회사에 팔린 뒤 업데이트로 광고나 추적 코드가 끼어드는 사례도 있다. 스토어의 '업데이트 날짜'와 '개발자'를 가끔 다시 확인하자.

07

너무 좋은 약속

신호: “무료 무제한 VPN”, “모든 영상 다운로드”, “유료 기능 공짜로”

공짜로 많은 것을 준다는 말 뒤에는 대가가 있다. 대개 그 대가는 내 방문 기록과 개인 정보다. 약속이 클수록 권한 목록과 개인정보처리방침을 더 꼼꼼하게 본다.
